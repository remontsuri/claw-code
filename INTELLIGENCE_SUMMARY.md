### 2. Реализация (2 модуля)

#### rust/crates/tools/src/web_api.rs
Универсальный HTTP клиент для работы с любыми REST API:
- ✅ Поддержка GET, POST, PUT, DELETE, PATCH
- ✅ Гибкая аутентификация (Bearer, Basic, API Key)
- ✅ Настраиваемые заголовки
- ✅ Автоматический парсинг JSON
- ✅ Таймауты и обработка ошибок
- ✅ Полное покрытие тестами

**Размер:** ~300 строк кода
**Тесты:** 3 unit теста

#### rust/crates/tools/src/ai_inference.rs
Модуль для вызова других AI моделей:
- ✅ Поддержка Ollama (локальные модели)
- ✅ Поддержка OpenAI API (GPT-4, GPT-3.5)
- ✅ Поддержка Anthropic API (Claude)
- ✅ Кастомные endpoints
- ✅ Контроль температуры и max_tokens
- ✅ Отслеживание использования токенов
- ✅ Автоматическое определение провайдера

**Размер:** ~350 строк кода
**Тесты:** 3 unit теста

## 🚀 Как использовать

### Быстрый старт

1. **Запустить скрипт интеграции:**
```powershell
.\integrate_intelligence.ps1
```

2. **Использовать новые возможности:**
```bash
# Работа с API
.\rust\target\release\claw.exe "используй WebAPI чтобы получить данные о пользователе octocat с GitHub"

# Вызов другой AI модели
.\rust\target\release\claw.exe "используй AIInference с qwen2.5-coder:7b чтобы оптимизировать этот код"
```

### Ручная интеграция

Если автоматический скрипт не работает, следуйте инструкциям в `INTEGRATION_GUIDE.md`.

- ✅ Таймауты для всех запросов
