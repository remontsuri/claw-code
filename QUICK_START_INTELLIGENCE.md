## 🎯 Примеры использования

### 1. Работа с GitHub API

```bash
claw "используй WebAPI чтобы получить информацию о пользователе octocat с GitHub API"
```

**Что произойдет:**
1. AI вызовет `https://api.github.com/users/octocat`
2. Получит JSON с данными
3. Проанализирует и покажет результат

### 2. Использование специализированной модели для кода

```bash
claw "используй AIInference с моделью qwen2.5-coder:7b чтобы написать функцию быстрой сортировки на Rust"
```

**Что произойдет:**
1. AI вызовет локальную модель qwen2.5-coder:7b
2. Получит оптимизированный код
3. Покажет результат с объяснениями

### 3. Поиск и получение данных

```bash
claw "найди в интернете последнюю версию Node.js, затем используй WebAPI чтобы получить changelog"
```

**Что произойдет:**
1. AI выполнит поиск в интернете
2. Найдет официальный сайт Node.js
3. Вызовет API для получения changelog
4. Проанализирует изменения

### 4. Комплексная задача

```bash
claw "получи список моих репозиториев с GitHub, найди самый популярный, прочитай его README и используй AIInference чтобы написать краткое описание"
```

**Что произойдет:**
1. Вызов GitHub API для списка репозиториев
2. Анализ звезд и выбор самого популярного
3. Получение README через API
4. Вызов AI модели для создания описания
5. Показ результата

## 🔧 Настройка (опционально)

### Переменные окружения

```powershell
# OpenAI (если хотите использовать GPT-4)
$env:OPENAI_API_KEY = "sk-..."

# Anthropic (если хотите использовать Claude)
$env:ANTHROPIC_API_KEY = "sk-ant-..."

# Ollama (по умолчанию localhost:11434)
$env:OLLAMA_BASE_URL = "http://localhost:11434"

# GitHub (для приватных репозиториев)
$env:GITHUB_TOKEN = "ghp_..."
```

### Сохранить переменные постоянно

```powershell
# Windows
[System.Environment]::SetEnvironmentVariable("OPENAI_API_KEY", "sk-...", "User")

# Или добавьте в PowerShell профиль
notepad $PROFILE
# Добавьте: $env:OPENAI_API_KEY = "sk-..."
```

## 🐛 Решение проблем

### Проблема: "Ollama не найдена"

```powershell
# Проверьте, что Ollama запущена
ollama list

# Если не запущена
ollama serve
```

### Проблема: "API ключ не найден"

```powershell
# Установите переменную окружения
$env:OPENAI_API_KEY = "sk-..."

# Или используйте только локальные модели (Ollama)
claw "используй AIInference с llama3.2"
```

### Проблема: "Модель не найдена"

```powershell
# Скачайте модель
ollama pull llama3.2
ollama pull qwen2.5-coder:7b

# Проверьте список моделей
ollama list
```

### Проблема: "Медленная работа"

```powershell
# Убедитесь, что используется GPU
$env:OLLAMA_VULKAN = "1"
$env:GGML_VK_VISIBLE_DEVICES = "0"

# Перезапустите Ollama
taskkill /F /IM ollama.exe
ollama serve
```

## 💡 Советы

### Для лучшей производительности

1. **Используйте GPU** - Ollama с GPU работает в 10-50 раз быстрее
2. **Выбирайте правильную модель** - для кода используйте qwen2.5-coder:7b
3. **Кешируйте результаты** - AI запоминает контекст в рамках сессии
4. **Используйте streaming** - для длинных ответов

### Для лучших результатов

1. **Будьте конкретны** - "используй WebAPI для GET запроса" лучше чем "получи данные"
2. **Указывайте модель** - "используй AIInference с qwen2.5-coder:7b" для кода
3. **Разбивайте задачи** - сложные задачи разбивайте на шаги
4. **Проверяйте результаты** - AI может ошибаться, всегда проверяйте
